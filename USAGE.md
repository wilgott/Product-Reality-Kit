# Usage

Product Reality Kit does not need installation.

It is a Markdown toolkit. You can read it on GitHub, clone it locally, copy templates into your team tools, or ask an AI assistant to use the files as source material.

---

## Use it on GitHub

Start with the diagnostic that matches the situation:

- Sales pressure: [When Sales Drives the Roadmap](diagnostics/when-sales-drives-the-roadmap.md)
- Enterprise exception: [When Enterprise Wants an Exception](diagnostics/when-enterprise-wants-an-exception.md)
- Pricing confusion: [When Pricing Is Confusing](diagnostics/when-pricing-is-confusing.md)
- Weak launch: [When the Launch Does Not Land](diagnostics/when-the-launch-does-not-land.md)
- Weak activation: [When Activation Is Weak](diagnostics/when-activation-is-weak.md)
- Low feature adoption: [When Feature Adoption Is Low](diagnostics/when-feature-adoption-is-low.md)
- Churn: [When Customers Churn](diagnostics/when-customers-churn.md)
- Configurability pressure: [When "Just Make It Configurable" Sounds Easy](diagnostics/when-just-make-it-configurable-sounds-easy.md)

Then write the decision with one of the Product Decision Record templates:

- [Product Decision Record](decision-records/product-decision-record.md)
- [Lite Product Decision Record](decision-records/product-decision-record-lite.md)
- [Confluence copy-paste version](decision-records/confluence-copy-paste.md)

---

## Clone it locally

Use this if you want the toolkit available on your machine or inside an AI coding client.

```bash
git clone https://github.com/wilgott/Product-Reality-Kit.git
cd Product-Reality-Kit
```

There is no package install step.

---

## Use it with AI tools

You can use Product Reality Kit with Codex, Claude Code, OpenClaw, or any AI tool that can read files from a local folder.

Open the cloned repo in the tool, then ask it to use the relevant diagnostic and Product Decision Record template.

Example:

```text
Use Product Reality Kit as source material.

Situation:
[paste the real context]

Use:
- diagnostics/when-sales-drives-the-roadmap.md
- decision-records/product-decision-record.md

Help me diagnose the situation and draft a Product Decision Record.

Do not invent evidence.
Separate what we know from what we do not know.
Keep the language clear and practical.
```

For a different situation, replace the diagnostic path with the file that matches your problem.

---

## Good ways to use the output

Use AI output to:

- Find weak assumptions.
- Prepare better questions for Sales, CS, Engineering, Support, Marketing, or leadership.
- Compare decision options.
- Draft a clearer Product Decision Record.
- Explain the trade-off in plain language.

Do not use AI output to replace product judgment.

Check the facts yourself.
